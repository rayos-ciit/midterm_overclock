# midterm submission

**Game Name:** Overclock

**Student Name:** Janrein S. Rayos

**Description:** 

The base is under attack.. (again)

Rogue subroutines are attempting to breach the base, and autonomous defenses are no longer sufficient. As the newly appointed defense operator, your job is to build a perimeter, manage resources, and repel the intrusion.

When the autonomous protocols fail, you must intervene. 
Take direct manual control of the turret nodes, override their safeties, and OVERCLOCK the system.

**Controls:** 

Left Click: Deploy Node / Select Node / Overclock Node / Fire (in Overclock Mode)
U: Upgrade Hovered/Selected Node
X: Scrap (Sell) Hovered/Selected Node
Right Click / R: Terminate Override (Return node to Auto-mode)
P: Pause Simulation
